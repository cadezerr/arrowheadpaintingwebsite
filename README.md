# Arrowhead Painting KC — Website

Website for **arrowheadpaintingkc.com**, built as static HTML, CSS, and JavaScript and hosted on **GoDaddy Node.js Hosting** (deployed from this GitHub repo).

## How it's organized

| What | Where |
|------|-------|
| Pages | `src/pages/` (folders become URLs, e.g. `src/pages/blog/my-post.html` → `/blog/my-post/`) |
| Service-area city pages | Generated by `scripts/make-areas.py` (edit the copy there, then run it) |
| Header, footer, call-to-action band, quote form | `src/partials/` (edit once, updates every page) |
| Reviews | `src/data/reviews.json` |
| Colors, fonts, layout | `src/assets/styles.css` (brand colors at the top) |
| Photos | `src/assets/img/` (WebP, multiple sizes) |
| Quote form email | `server.js` → `/api/contact` |

`npm run build` assembles everything into `dist/`. `npm start` runs the site. GoDaddy runs both automatically, and there are no packages to install.

## GoDaddy settings

Under **Settings → Secrets** in Node.js Hosting:

| Name | Value |
|------|-------|
| `CONTACT_FORM_RECIPIENT_EMAIL` | the address that should receive estimate requests |

## Publishing a change

After a change is pushed to `main`, select **Pull from GitHub** in Node.js Hosting.

## Photos and videos still wanted

Placeholders are marked in the code with `PHOTO NEEDED`.

- **Bobby (project manager):** a portrait, ideally a vertical 4:5 shot, outdoors in branded gear. Used on the About page.
- **Wood rot before/after pairs:** the same spot photographed before and after the repair (door frame, trim, fascia). Shoot from the same angle and distance. Used on Our Work and Wood Rot Repair.
- **Hero video (optional):** a 10–20 second drone clip circling a finished home, landscape, no text overlays. Export as MP4 (1080p, under 8 MB). Save it as `src/assets/video/hero.mp4` and swap it in on the home page.
- **Crew at work:** a few wide shots of the crew prepping and painting. Bright daylight works best.
